# Vue Components

Production-ready Vue 3 components following the DevSnips minimal design system.

## Design principles

- Minimal visual language
- Responsive and adaptive layouts
- Vue 3 Composition API
- Accessible keyboard interactions and focus states
- Touch-friendly controls
- No unnecessary dependencies
- Consistent spacing, typography, borders, and states

## Phase 1

40 foundational components across Buttons & Actions, Forms & Inputs, Selection, and Navigation.

Each component is designed to adapt rather than merely shrink on smaller screens.
