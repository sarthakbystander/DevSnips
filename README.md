## Why DevSnips?

Stop paying $299 for polished UI kits. Get 850+ production-ready variants, design tokens across 15+ visual styles,and complete multi-page templates — from AI SaaS platforms to conference sites — completely free under the [MIT license](LICENSE).

## Featured templates

- [AI SaaS Platform](Tailwind/Templates/ai-saas-platform/preview.html) — a complete multi-page AI SaaS product site
- [Northstar Vanilla Dashboard](Vanilla/Templates/SaaS%20Dashboard/) — a 30-page SaaS admin dashboard in vanilla HTML/CSS/JS
- [Stratum](Tailwind/Templates/stratum/preview.html) — a fintech ops platform landing page

## Quick Start (30 seconds)

```bash
git clone https://github.com/sarthakbystander/DevSnips.git
cd DevSnips

# Optional: serve the library locally for an interactive gallery
python3 -m http.server 8080
# then open http://localhost:8080/ in your browser
```
