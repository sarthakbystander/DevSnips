# Blog Card

Editorial blog card with featured image, category tag, author info, and engagement affordances.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Featured image
- Category badge
- Author metadata
- Optional engagement actions

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/blog-card
```

Copy from `code.html`.

## Customization

- Image aspect, typography, badge colors, spacing

## Accessibility

- Meaningful `alt` text for images
- Real links/buttons for actions

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
