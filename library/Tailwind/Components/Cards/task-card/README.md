# Task Card

Task / to-do card.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Task title and meta
- Status / assignee affordances

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/task-card
```

Copy from `code.html`.

## Customization

- Checkbox / status styles, spacing

## Accessibility

- Interactive controls must be native and labeled

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
