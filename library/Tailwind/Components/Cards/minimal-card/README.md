# Minimal Card

Minimal content card with restrained chrome.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Minimal surface
- Clear title / body hierarchy

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/minimal-card
```

Copy from `code.html`.

## Customization

- Border, radius, spacing, typography

## Accessibility

- Prefer real headings for titles

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
