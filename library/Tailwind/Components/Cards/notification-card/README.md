# Notification Card

In-app notification card.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Icon / status + message
- Timestamp / actions

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/notification-card
```

Copy from `code.html`.

## Customization

- Status colors, typography, spacing

## Accessibility

- Do not rely on color alone for status

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
