# Music Card

Music / track card with cover art and meta.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Cover art
- Track / artist meta
- Optional playback affordance

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/music-card
```

Copy from `code.html`.

## Customization

- Art size, typography, action styles

## Accessibility

- Meaningful `alt` for cover art; real controls for play actions

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
