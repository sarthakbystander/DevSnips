# Timeline Card

Timeline event card.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Time marker
- Event title and body

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/timeline-card
```

Copy from `code.html`.

## Customization

- Marker colors, typography, spacing

## Accessibility

- Keep chronological text readable without relying on visual markers alone

## Dependencies

- Tailwind CSS only
