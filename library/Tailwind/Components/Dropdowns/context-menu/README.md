# Context Menu

Right-click / context menu pattern.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Context positioning
- Action list

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/context-menu
```

Copy from `code.html`.

## Customization

- Menu surface and item styles

## Accessibility

- Provide keyboard alternatives to pointer-only context actions

## Dependencies

- Tailwind CSS; JS for positioning/open state as present
