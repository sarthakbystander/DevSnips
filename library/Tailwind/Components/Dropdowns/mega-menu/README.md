# Mega Menu

Wide multi-column mega menu.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Multi-column layout
- Sectioned links

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/mega-menu
```

Copy from `code.html`.

## Customization

- Column layout, typography, spacing

## Accessibility

- Keyboard navigation across columns

## Dependencies

- Tailwind CSS; JS as present

- `code.html` · `preview.html` · `metadata.json` · `README.md`
