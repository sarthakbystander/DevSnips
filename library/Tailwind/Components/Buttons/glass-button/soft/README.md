# Glass Button Soft

Soft glassmorphism button with label.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Soft glass surface
- Focus-visible states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/glass-button/soft
```

Copy from `code.html`.

## Customization

- Blur, opacity, border, text colors

## Accessibility

- Native `<button>` with visible label

## Dependencies

- Tailwind CSS only
