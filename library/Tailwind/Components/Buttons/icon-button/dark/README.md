# Icon Button Dark

Dark-themed icon button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Dark surface treatment
- Icon-only layout
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/icon-button/dark
```

Copy from `code.html`.

## Customization

- Dark palette utilities, icon color

## Accessibility

- Provide `aria-label` for icon-only buttons

## Dependencies

- Tailwind CSS only
