# Social Button Google

Google-branded social button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Brand color treatment
- Icon + label layout
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/social-button/google
```

Copy from `code.html`.

## Customization

- Brand colors, icon, padding

## Accessibility

- Native `<button>` or link with clear accessible name

## Dependencies

- Tailwind CSS only
