# Social Button Facebook

Facebook-branded social button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Brand color treatment
- Icon + label layout
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/social-button/facebook
```

Copy from `code.html`.

## Customization

- Brand colors (respect brand guidelines), icon, padding

## Accessibility

- Native `<button>` or link with clear accessible name

## Dependencies

- Tailwind CSS only
