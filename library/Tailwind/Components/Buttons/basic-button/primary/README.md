# Basic Button Primary

Primary call-to-action basic button.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Primary emphasis styling
- Focus-visible states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/basic-button/primary
```

Copy from `code.html`. No JavaScript required.

## Customization

- Primary background / text / hover colors
- Padding, radius, typography
- Focus ring

## Accessibility

- Native `<button>`
- Focus-visible styles

## Dependencies

- Tailwind CSS only

- `code.html` — copy/paste snippet
- `preview.html` — standalone demo
