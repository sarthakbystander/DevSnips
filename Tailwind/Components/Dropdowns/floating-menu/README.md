# Floating Menu

Floating positioned dropdown menu.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Floating placement
- Menu item list

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/floating-menu
```

Copy from `code.html`.
