# Multi Select

Multi-select dropdown.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Multiple selection
- Selected value presentation

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/multi-select
```

Copy from `code.html`.

## Customization

- Chip / tag styles for selected items, list styles

## Accessibility

- Selected state must be exposed to assistive tech

## Dependencies

- Tailwind CSS; JS as present

- `code.html` · `preview.html` · `metadata.json` · `README.md`
