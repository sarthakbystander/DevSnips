# Theme Switcher

Theme selection dropdown (light/dark/system, etc.).

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Theme options
- Current selection presentation

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/theme-switcher
```

Copy from `code.html`. Wire selection to your theme system.

## Customization

- Option icons/labels, trigger styles

## Accessibility

- Expose the current theme accessibly

## Dependencies

- Tailwind CSS; JS as present

- `code.html` · `preview.html` · `metadata.json` · `README.md`
