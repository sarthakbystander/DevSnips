# Multi Open Accordion

Faceted filter panel where multiple sections stay open at once. Designed for filter UIs, settings groups, and any case where users need several sections visible simultaneously.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Multiple sections can be open at the same time
- Independent toggles
- Clear open/closed visual state
- Focus-visible rings
- ARIA state attributes

## Usage

```bash
npx devsnips add Tailwind/Components/Accordions/multi-open-accordion
```

Copy from `code.html`. Keep the inline script or reimplement the same toggle + ARIA updates.

## Customization

- Colors, spacing, typography
- Open-state styling
- Focus ring

## Accessibility

- Native buttons + ARIA expanded/controls
- Keyboard focus styles

## Responsive Behavior

Fluid width; stacks on small screens.

## Dependencies

- Tailwind CSS
- Small inline JavaScript
