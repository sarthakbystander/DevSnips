# Minimal Accordion

Borderless, typography-led accordion with a plus/minus indicator. Ideal for clean documentation and content-heavy pages where visual chrome should stay minimal.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Borderless / typography-led design
- Plus/minus indicator
- Smooth expand/collapse
- Focus-visible rings
- ARIA state attributes
- Native button triggers

## Usage

```bash
npx devsnips add Tailwind/Components/Accordions/minimal-accordion
```

Copy the markup from `code.html` into a Tailwind project. Include the inline script for interactivity.

## Customization

- Typography scale and weight
- Indicator color and size
- Spacing between items
- Focus ring utilities

## Accessibility

- Native buttons
- ARIA expanded/controls attributes
- Visible focus states

## Responsive Behavior

Fluid width; no heavy breakpoint overrides.

## Dependencies

- Tailwind CSS
- Small inline JavaScript
