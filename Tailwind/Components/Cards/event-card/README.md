# Event Card

Event listing card (date, title, location).

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Date emphasis
- Title and meta

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/event-card
```

Copy from `code.html`.

## Customization

- Date badge styling, typography, spacing

## Accessibility

- Prefer machine-readable dates when possible

## Dependencies

- Tailwind CSS only

- `code.html` · `preview.html` · `metadata.json` · `README.md`
