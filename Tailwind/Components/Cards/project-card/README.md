# Project Card

Project summary card.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Project title and status
- Meta / progress affordances

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/project-card
```

Copy from `code.html`.

## Customization

- Status colors, typography, spacing

## Accessibility

- Do not rely on color alone for status

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
