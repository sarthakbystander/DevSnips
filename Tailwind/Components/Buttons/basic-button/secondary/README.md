# Basic Button Secondary

Secondary basic button for supporting actions.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Secondary styling
- Focus-visible states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/basic-button/secondary
```

Copy from `code.html`.

## Customization

- Secondary palette, borders, hover states
- Spacing and radius

## Accessibility

- Native `<button>`
- Focus-visible styles

## Dependencies

- Tailwind CSS only
