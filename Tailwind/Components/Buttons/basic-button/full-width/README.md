# Basic Button Full Width

Full-width basic button variant for forms, mobile CTAs, and stacked actions.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Full-width layout (`w-full`)
- Clear focus states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/basic-button/full-width
```

Copy from `code.html`.

## Customization

- Background / text / border colors
- Padding and radius
- Focus ring

## Accessibility

- Native `<button>`
- Focus-visible styles

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` — copy/paste snippet
- `preview.html` — standalone demo
