# Basic Button Sizes

Basic button size scale (small / medium / large).

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Multiple size variants
- Consistent focus states
- Native buttons

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/basic-button/sizes
```

Copy the size classes you need from `code.html`.

## Customization

- Size-specific padding and text classes
- Colors and radius

## Accessibility

- Native `<button>`
- Adequate touch target sizes recommended for the small variant

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` — copy/paste snippet
- `preview.html` — standalone demo
- `metadata.json` — metadata
- `README.md` — this file
