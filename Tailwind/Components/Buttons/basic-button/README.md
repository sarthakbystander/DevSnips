# Basic Button

Foundation button styles with semantic color variants.

## Variants

| Variant | Description |
|---------|-------------|
| [Primary](./primary/) | Primary action buttons with blue color |
| [Secondary](./secondary/) | Secondary buttons with multiple color options |
| [Neutral](./neutral/) | Buttons designed for dark backgrounds |
| [Sizes](./sizes/) | All button sizes from small to extra large |
| [Full Width](./full-width/) | Full width and split width buttons |

## Quick Start

```html
<button class="px-6 py-2.5 bg-blue-600 text-white font-medium rounded-lg hover:bg-blue-700 focus:outline-none focus:ring-2 focus:ring-blue-500 focus:ring-offset-2">
  Click Me
</button>
```

## Accessibility

- All buttons include visible focus rings
- Use `disabled` attribute for disabled state
- Minimum touch target: 44×44px
