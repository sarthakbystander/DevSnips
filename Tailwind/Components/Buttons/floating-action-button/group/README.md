# Floating Action Button Group

Grouped floating action buttons.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Grouped FAB layout
- Elevation
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/floating-action-button/group
```

Copy from `code.html`.

## Customization

- Gap, colors, shadows
- Individual button styles

## Accessibility

- Each control should remain a native button with an accessible name

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` — copy/paste snippet
- `preview.html` — standalone demo
- `metadata.json` — metadata
