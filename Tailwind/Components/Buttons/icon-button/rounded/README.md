# Icon Button Rounded

Fully rounded icon button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Circular / highly rounded shape
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/icon-button/rounded
```

Copy from `code.html`.

## Customization

- Size, colors, icon

## Accessibility

- Provide `aria-label` for icon-only buttons

## Dependencies

- Tailwind CSS only

- `code.html` · `preview.html` · `metadata.json` · `README.md`
