# Gradient Button Shadow

Gradient button with colored shadow emphasis.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Gradient fill + colored shadow
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/gradient-button/shadow
```

Copy from `code.html`.

## Customization

- Gradient stops and shadow color utilities

## Accessibility

- Native `<button>`

## Dependencies

- Tailwind CSS only
