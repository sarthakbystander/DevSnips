# Basic Button Neutral

Neutral / secondary-styled basic button for less prominent actions.

## Preview

Open `preview.html` for a standalone demonstration of this variant.

## Features

- Neutral color treatment
- Focus-visible states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/basic-button/neutral
```

Copy from `code.html`.

## Customization

- Neutral palette utilities
- Spacing and radius

## Accessibility

- Native `<button>`
- Focus-visible styles

## Dependencies

- Tailwind CSS only

- `code.html` — copy/paste snippet
