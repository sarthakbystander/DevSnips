# DevSnips Engineering Reports

This directory contains persistent engineering analyses, audits, investigations, and launch readiness assessments for the DevSnips repository.

## Naming Convention

Reports should follow descriptive kebab-case naming with ISO dates:
`[topic]-audit-[YYYY-MM-DD].md`

## Guidelines

- Reports must be factual, evidence-backed, and cite exact files and paths.
- Avoid speculative or unverified claims.
- Never include sensitive information (tokens, keys, credentials).
- Do not overwrite historical reports; create new versioned reports if re-evaluating.
