# Features — Tabs

A production-ready DevSnips React Features section in the **Tabs** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { FeaturesSection } from "./code";

export default function Page() {
  return <FeaturesSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace feature copy, labels, icons, and actions.

## Accessibility

Preserve semantic headings, tab semantics, keyboard navigation, and visible focus states.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
- `metadata.json` — registry metadata
