# Contact — Dark Premium

A production-ready DevSnips React Contact section in the **Dark Premium** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { ContactSection } from "./code";

export default function Page() {
  return <ContactSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace copy, field labels, contact details, and actions.

## Accessibility

Keep every form field labeled, preserve validation messaging, and retain visible focus states.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
- `metadata.json` — registry metadata
