# Hero — Neo Brutalist

A production-ready DevSnips React Hero section in the **Neo Brutalist** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { HeroSection } from "./code";

export default function Page() {
  return <HeroSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace the eyebrow, heading, copy, actions, and supporting content.

## Accessibility

Preserve the heading hierarchy, link labels, navigation landmark, and visible focus states.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
- `metadata.json` — registry metadata
