# Pricing — Dark Premium

A production-ready DevSnips React Pricing section in the **Dark Premium** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { PricingSection } from "./code";

export default function Page() {
  return <PricingSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace plan names, prices, features, and actions.

## Accessibility

Preserve heading hierarchy, plan relationships, labels, and visible focus states.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
- `metadata.json` — registry metadata
