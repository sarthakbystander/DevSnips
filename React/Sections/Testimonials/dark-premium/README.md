# Testimonials — Dark Premium

A production-ready DevSnips React Testimonials section in the **Dark Premium** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { TestimonialsSection } from "./code";

export default function Page() {
  return <TestimonialsSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace testimonials and supporting copy.

## Accessibility

Preserve semantic headings, meaningful attribution, and visible focus states when customizing interactive content.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
