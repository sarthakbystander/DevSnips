# Team — Neo Brutalist

A production-ready DevSnips React Team section in the **Neo Brutalist** direction.

## Usage

`code.tsx` is the authored implementation and `code.jsx` exposes the same public API. See `code.tsx` for the exact props and defaults.

```tsx
import { TeamSection } from "./code";

export default function Page() {
  return <TeamSection />;
}
```

## Customization

Use the props documented in `code.tsx` to replace team members, roles, portraits, and links.

## Accessibility

Use meaningful alternative text for portraits and preserve heading hierarchy and link labels.

## Files

- `code.tsx` — authored TypeScript implementation
- `code.jsx` — JavaScript API parity entrypoint
- `preview.html` — runnable preview
- `metadata.json` — registry metadata
