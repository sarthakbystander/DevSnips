DevSnips / Docs

Build with what is already built.

DevSnips is an open-source UI library organized around reusable code. Browse resources, copy the implementation, or pull them into a project with the CLI.

Library structure

Resources are grouped by technology and abstraction level. Each resource carries its implementation alongside readable documentation and metadata, so the same source can power the repository, CLI and website.

CLI

Use the DevSnips CLI when you want a resource directly in your project.

$ npx devsnips add Tailwind/Sections/AI-Product

Contributing

DevSnips is MIT licensed and built in public. New resources should follow the structure and metadata conventions documented in the repository.
