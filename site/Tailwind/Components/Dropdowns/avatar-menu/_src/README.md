# Avatar Menu

User avatar dropdown menu.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Avatar trigger
- Account / settings links

## Usage

```bash
npx devsnips add Tailwind/Components/Dropdowns/avatar-menu
```

Copy from `code.html`.

## Customization

- Avatar size, menu width, item styles

## Accessibility

- Trigger needs an accessible name; manage focus for the menu

## Dependencies

- Tailwind CSS; small JS if script is present

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
