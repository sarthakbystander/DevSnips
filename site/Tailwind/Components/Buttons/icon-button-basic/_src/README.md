# Icon Button Basic

Basic icon-only button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Icon-only control
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/icon-button/basic
```

Copy from `code.html`. Always supply an accessible name.

## Customization

- Icon, size, colors, radius

## Accessibility

- Use `aria-label` (or visible text) for icon-only buttons

## Dependencies

- Tailwind CSS only

## File Structure

- `code.html` · `preview.html` · `metadata.json` · `README.md`
