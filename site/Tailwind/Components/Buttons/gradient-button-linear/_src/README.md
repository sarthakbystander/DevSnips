# Gradient Button Linear

Linear gradient filled button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Linear gradient background
- Focus-visible states
- Native button

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/gradient-button/linear
```

Copy from `code.html`.

## Customization

- Gradient stops (`from-*` / `via-*` / `to-*`)
- Hover brightness / opacity

## Accessibility

- Native `<button>`
- Ensure text contrast against the gradient

## Dependencies

- Tailwind CSS only
