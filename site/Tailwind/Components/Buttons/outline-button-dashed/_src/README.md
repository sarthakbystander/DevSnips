# Outline Button Dashed

Dashed outline button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Dashed border treatment
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/outline-button/dashed
```

Copy from `code.html`.

## Customization

- Border style/color, text color, hover fill

## Accessibility

- Native `<button>`

## Dependencies

- Tailwind CSS only
