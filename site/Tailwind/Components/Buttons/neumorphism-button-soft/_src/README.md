# Neumorphism Button Soft

Soft neumorphic button.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Soft-UI / neumorphic shadows
- Focus-visible states

## Usage

```bash
npx devsnips add Tailwind/Components/Buttons/neumorphism-button/soft
```

Copy from `code.html`.

## Customization

- Shadow values and surface color

## Accessibility

- Native `<button>`

## Dependencies

- Tailwind CSS only
