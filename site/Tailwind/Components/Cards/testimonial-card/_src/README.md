# Testimonial Card

Customer testimonial card.

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Quote body
- Attribution (name, role, avatar)

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/testimonial-card
```

Copy from `code.html`.

## Customization

- Quote typography, avatar size, spacing

## Accessibility

- Prefer semantic quote markup when appropriate

## Dependencies

- Tailwind CSS only

- `code.html` · `preview.html` · `metadata.json` · `README.md`
