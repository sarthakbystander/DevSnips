# Course Card

Course / learning content card (title, instructor, meta).

## Preview

Open `preview.html` for a standalone demonstration.

## Features

- Course media + title
- Instructor / meta row
- Optional progress or CTA

## Usage

```bash
npx devsnips add Tailwind/Components/Cards/course-card
```

Copy from `code.html`.

## Customization

- Image aspect, badge colors, spacing

## Accessibility

- Meaningful image `alt`; real controls for CTAs

## Dependencies

- Tailwind CSS only

- `code.html` · `preview.html` · `metadata.json` · `README.md`
