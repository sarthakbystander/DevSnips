Frosted-glass notification toasts in the glassmorphism design language — translucent backdrop-blur panels with semantic glowing accents, a live countdown progress bar, and pause-on-hover, presented over an animated aurora mesh backdrop.

Compact pill-shaped toast for terse, icon-led feedback like "Copied!" or "Saved". No body text — just an icon and a label. Appears centered at the bottom and fades after 2 seconds.

 toasts

Persistent Toast

Toast that stays open until explicitly dismissed, with a shrinking progress bar showing the remaining time. The bar pauses on hover and resumes on leave. Ideal for upload results and important notices that shouldn't be missed.

 toasts

Promise Toast

Async-operation toast that opens in a loading state and transitions in place to success or error when a promise settles. Pass any promise to showPromiseToast() with loading/success/error copy; once settled it auto-dismisses behind a pause-on-hover countdown bar.

 toasts

Stacked Toasts

Notification queue that stacks incoming toasts vertically. New toasts push older ones up with a staggered slide-in, and each clears itself on its own 5-second timer. Includes a dismiss-all control.

 toasts

Status Toasts

Four semantic toast variants — success, error, warning, info — each with a matching icon, accent color, and ARIA role. Errors and warnings use role=alert; success and info use role=status.

Tooltip that waits 600ms before appearing on hover so quick mouse-overs don't flicker, then hides instantly on exit. Uses CSS transition-delay - no JavaScript timers. Appears instantly on keyboard focus.

Directional Tooltip

Tooltips in all four directions - top, right, bottom, left - with arrows that reposition automatically. Direction is controlled by the data-tooltip-pos attribute. Pure CSS, no JavaScript.

Hotspot Tooltip

Onboarding hotspot beacon that opens a multi-step guided tour tooltip. Click the pulsing beacon to start; Next/Done walk the steps, Skip or Escape dismiss it.

Icon Tooltip

Tooltip on an icon-only button - the key accessibility use case where the tooltip serves as the visible label. Each icon button carries aria-label and a role=tooltip companion so screen readers announce the action. Pure CSS.

Rich Tooltip

Wide tooltip with rich content - a title plus a multi-line description - ideal for help text on form fields and complex UI elements. Pure CSS using two data attributes, hover or focus to reveal.

Selection Toolbar

A floating toolbar that appears above any selected text inside its article scope, offering Highlight (real <mark> wrap), Copy, and Share actions. Positions itself over the selection with viewport clamping and re-tracks on scroll and resize.

Status Tooltip

Status indicator dot with a color-themed tooltip - success (green), warning (amber), error (red), info (blue). The tooltip background and arrow match the semantic status. Pure CSS, hover or focus to reveal.
