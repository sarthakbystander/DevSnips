# Developer Portfolio

Editorial, minimal developer portfolio built on the DevSnips design-token system.

**Technology:** Vanilla HTML / CSS / JS  
**Category:** templates  
**Subcategory:** developer-portfolio

## Features

- Shared `--ds-*` design tokens (light + dark)
- Strong typography hierarchy and restrained spacing
- Realistic project content and skills
- Sticky header with theme toggle
- Accessible focus states and reduced-motion support
- Zero dependencies

## Structure

```
freelancer-portfolio/
├── pages/
│   └── index.html      # Full single-page template
├── preview.html        # Canonical preview
├── metadata.json
└── README.md
```

Open `preview.html` or `pages/index.html` directly in a browser.
