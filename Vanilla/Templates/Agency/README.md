# DevSnips Agency

A premium editorial agency website template built with semantic HTML, CSS, Vanilla JavaScript, and Pico CSS.

## Files

- `preview.html` — canonical self-contained DevSnips preview
- `code.html` — modular HTML source
- `style.css` — custom styling and design tokens
- `script.js` — navigation, reveal, and scroll interactions
- `metadata.json` — DevSnips template metadata

## Design

The template follows `Vanilla/Templates/design-tokens.md` as the shared visual source of truth. It uses a high-contrast editorial layout, restrained borders, typography-led hierarchy, asymmetric project compositions, and responsive behavior.

## Usage

Open `code.html` directly or copy the HTML, CSS, and JavaScript into an existing project. No build step or backend is required.

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Pico CSS

## Responsive

Designed for desktop, tablet, and mobile with an intentionally restructured mobile navigation and content layout. The page avoids horizontal overflow and supports reduced motion.
