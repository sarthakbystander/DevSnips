# Stats Grid

4 colored stat tiles with animated counters.

**Technology:** Vanilla HTML/CSS/JS  
**Category:** sections / statistics  
**Design:** Neo-Brutalist (flat colors, hard shadows, bold borders)  
**Responsive:** Mobile-first (320px → 1920px)  
**Dark mode:** via `prefers-color-scheme`  

**Tags:** stats, counters, animated  
**Features:** IntersectionObserver, reduced-motion safe, aria

## Usage

1. Copy the contents of `stats-grid.html` into your page.
2. The section is self-contained (inline CSS + JS). No build step.
3. Tweak the CSS variables in `:root` to rebrand.
