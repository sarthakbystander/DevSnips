# DaisyUI Launch Site

A standalone launch page built from DevSnips design patterns and Tailwind sections, using daisyUI for semantic UI primitives.

## Run

Open `index.html` directly in a browser. The page uses the Tailwind browser build and daisyUI CDN, so no local build step is required.

## Source inspiration

The visual direction adapts DevSnips' SaaS launch hero and reusable component patterns into a daisyUI-based product launch page.
